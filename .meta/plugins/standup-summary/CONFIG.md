# Stand-up Summary — Configuration

## Optional Settings

**FORMAT**  
Output register. Default: `spoken`  
Options: `spoken` | `async-text`

- `spoken` — 3–4 plain sentences, no formatting, designed to be read aloud
- `async-text` — slightly more structured, suitable for Slack/Teams standup threads

## Notes

- Default `spoken` format produces no bullet points, no markdown, no headers.
- Use `async-text` only if your team does standups via text and expects a structured format.
