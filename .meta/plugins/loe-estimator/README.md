# Plugin: LOE Estimator

**Pattern**: Prompts-only
**Invocation type**: On-demand
**Status**: Starter — LOE estimation is highly team-specific. This gives you a structured breakdown as a starting point; calibrate the complexity factors and sizing labels to your team's actual velocity and conventions.

---

## What It Does

Generates a level-of-effort estimate breakdown from a requirements description or feature list. Produces task-level effort buckets rather than a single number — more useful for planning conversations than a raw hour count.

## When to Use

- Early in an engagement when a client asks "how long will this take?"
- Before sprint planning when stories need rough sizing
- For proposal work when you need to scope an engagement

## Important Caveat

LOE estimation is inherently uncertain — especially from requirements alone. This plugin structures the breakdown and surfaces assumptions, but the estimates require human calibration against actual team velocity. Use the output as a starting point for a planning conversation, not a commitment.

## Starter Note

The complexity labels (S/M/L/XL) are placeholders. Replace them with your team's actual sizing convention (story points, days, T-shirt sizes, etc.) before using in client-facing work.
