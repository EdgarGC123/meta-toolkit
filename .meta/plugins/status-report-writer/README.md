# Plugin: Status Report Writer

**Pattern**: Prompts-only
**Invocation type**: On-demand or workflow-embedded
**Status**: Starter — customize status indicators and sections to match your stakeholder's expectations

---

## What It Does

Generates a concise project status update from action items, blockers, and recent progress notes. Designed for weekly or sprint-end reporting to stakeholders or project leads.

## When to Use

- Weekly status update to a client or project lead
- Sprint-end summary before a review
- When you need to translate working-level notes into a clean stakeholder-facing update

## Invocation Type Guidance

- **On-demand**: best for ad-hoc reporting
- **Workflow-embedded**: best if status reporting is a recurring step in your workflow (e.g., end of every sprint)
