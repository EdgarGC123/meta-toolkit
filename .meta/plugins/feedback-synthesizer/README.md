# Plugin: Feedback Synthesizer

**Pattern**: Prompts-only
**Invocation type**: On-demand
**Status**: Starter — works across survey responses, interview notes, and user feedback. Adjust the theme categories if your domain has specific feedback dimensions.

---

## What It Does

Takes raw feedback from multiple sources (survey responses, interview notes, Slack reactions, user testing notes) and synthesizes it into themes with supporting evidence and a recommended action per theme.

## When to Use

- After user research or stakeholder interviews
- After a sprint review or retrospective
- When you have a pile of feedback and need to present it coherently

## Note

The quality of synthesis depends heavily on input quality. Verbatim quotes produce better themes than paraphrased summaries. If you have the raw data, use it.
